## The joke

> My boss said his door is always open, so I asked for a raise through it and he closed it.

## How to run

```sh
node main.ts
```

This writes the joke to `/output/entry.txt`.

## Why this joke

"My door is always open" is the most quoted promise in office life — and the
least kept. The joke takes the promise literally: the door is open, so the
raise walks straight through it, and the boss's only move is to close the
door. True observation, one surprising last word, nothing wasted.
